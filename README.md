# dashboard-vendas-xbox-excel
Dashboard de vendas e assinaturas do Xbox Game Pass desenvolvido em Excel para o desafio da DIO.
O objetivo deste desafio é criar um dashboard de vendas, com foco na organização e visualização de dados. 
Transformando dados brutos em informações visuais claras e úteis, permitindo uma análise eficaz do
desempenho de vendas e a tomada de decisões baseadas em dados.
