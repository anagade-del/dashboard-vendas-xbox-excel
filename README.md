# 📊 Dashboard de Vendas do Xbox com Excel

## 📌 Sobre o Projeto

Projeto desenvolvido para o desafio "Criando um Dashboard de Vendas do Xbox", da DIO.

O objetivo é transformar dados de vendas e assinaturas do Xbox Game Pass em informações visuais claras, facilitando a análise de resultados e a tomada de decisões baseadas em dados.

## 🎯 Objetivos

- Organizar e analisar dados de assinaturas e vendas.
- Apresentar indicadores de faturamento.
- Explorar informações relacionadas aos planos e serviços adicionais.
- Desenvolver um painel visual para apoiar a análise de negócio.

## 🗂️ Dados Utilizados

A base de dados disponibilizada no desafio contém informações sobre assinaturas, planos, valores, renovação automática e serviços adicionais, como EA Play e Minecraft.

Os dados foram utilizados para construir análises de vendas e faturamento.

## 🛠️ Recursos Utilizados

- Microsoft Excel
- Organização e tratamento de dados
- Tabelas dinâmicas
- Cálculos e indicadores de faturamento
- Gráficos e visualização de dados
- GitHub e Markdown para documentação

## 📈 Análises Desenvolvidas

O projeto aborda informações sobre vendas e assinaturas do Xbox Game Pass, permitindo analisar o faturamento e explorar diferentes componentes da base de dados.

O dashboard foi desenvolvido para apresentar essas informações de forma visual e facilitar sua interpretação.

## 📂 Arquivo do Projeto

`PAINEL_EXCEL_ANAVI.xlsx`

O arquivo contém o trabalho desenvolvido em Excel para o desafio.

## ▶️ Como Reproduzir

1. Faça o download do arquivo `PAINEL_EXCEL_ANAVI.xlsx` neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Consulte a base de dados e as tabelas de apoio.
4. Acesse a área do dashboard para visualizar os indicadores e gráficos.
5. Explore as informações e os resultados apresentados.

## 💡 Aprendizados

O desenvolvimento deste projeto permitiu aplicar conhecimentos de organização de bases de dados, análise de informações, utilização de tabelas dinâmicas e construção de dashboards no Excel.

Também contribuiu para o desenvolvimento de competências em visualização de dados e comunicação de resultados para apoiar decisões de negócio.
